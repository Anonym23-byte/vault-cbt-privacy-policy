✅ Komitmen Privasi Siswa & Lembaga Pendidikan

Aplikasi Vault CBT Kiosk dirancang dengan prinsip Privacy by Design. Aplikasi ini TIDAK MENGUMPULKAN, TIDAK MENYIMPAN, DAN TIDAK MEMBAGIKAN data pribadi siswa (PII), foto kamera, atau riwayat penjelajahan ke server pihak ketiga mana pun.

1. Pengantar & Ruang Lingkup

Kebijakan Privasi ini menjelaskan bagaimana Vault CBT Kiosk ("Aplikasi", "Kami") memperlakukan informasi pengguna saat menjalankan aplikasi pada perangkat berbasis Android maupun peramban web.

Aplikasi ini berfungsi sebagai peramban terkunci (Lockdown Kiosk Browser) yang digunakan oleh sekolah, madrasah, universitas, dan lembaga pendidikan untuk menyelenggarakan Ujian Berbasis Komputer (CBT / CAT) yang aman, adil, dan tertib.

2. Izin Perangkat (Android Device Permissions) & Tujuannya

Aplikasi hanya meminta izin perangkat seminimal mungkin yang mutlak diperlukan untuk memastikan integritas sesi ujian:

  • Kamera (android.permission.CAMERA):
    Hanya digunakan untuk fitur pemindai QR Code (QR Code Scanner) saat siswa memindai tautan atau token server ujian sekolah. Tangkapan kamera diproses secara lokal secara real-time di memori perangkat melalui algoritma komputer vision dan tidak pernah direkam, disimpan, atau dikirimkan ke cloud.
  • Konektivitas Internet & Jaringan (INTERNET & ACCESS_NETWORK_STATE):
    Diperlukan untuk memuat konten ujian sekolah dari portal lokal (LAN) maupun portal daring (LMS / CBT Server seperti Moodle, Candy CBT, Google Forms, dll.).
  • Kunci Layar Penuh & Layar Aktif (WAKE_LOCK):
    Mencegah layar perangkat padam atau terkunci secara otomatis selama pengerjaan soal ujian sedang berlangsung.
  • Device Administration & Kiosk Lock Task (Opsional):
    Jika diizinkan oleh pengawas sekolah, aplikasi memanfaatkan API Android Lock Task Mode untuk mengunci tombol Navigasi, Beranda (Home), dan Aplikasi Terakhir (Recents) agar siswa tetap fokus pada lembar ujian tanpa gangguan notifikasi aplikasi lain.

4. Kebijakan Privasi Anak (COPPA Compliance)

Karena aplikasi ini ditujukan untuk lingkungan pendidikan termasuk siswa di bawah usia 13 tahun, kami sepenuhnya mematuhi ketentuan Children's Online Privacy Protection Act (COPPA) dan peraturan perlindungan data pribadi siswa.

Aplikasi tidak meminta informasi yang dapat mengidentifikasi individu anak, tidak menyediakan fitur obrolan sosial, dan tidak melakukan profiling perilaku.

5. Prosedur Penghapusan Data (Data Retention & Deletion)

Karena kami tidak mengelola database terpusat yang menyimpan identitas Anda, tidak ada data di server pengembang yang perlu dihapus.

Untuk menghapus seluruh pengaturan lokal (seperti URL ujian yang pernah diketikkan), pengguna cukup membuka: Pengaturan Android > Aplikasi > Vault CBT Kiosk > Penyimpanan > Hapus Data (Clear Data), atau menghapus pemasangan aplikasi (Uninstall).

1. Introduction & Overview

This Privacy Policy describes how Vault CBT Kiosk ("the Application", "We", "Us") handles information when used on Android devices and web platforms.

Vault CBT Kiosk is a hardened exam lockdown browser designed specifically for schools, universities, and educational test centers to conduct secure and tamper-resistant Computer-Based Testing (CBT).

2. Device Permissions & How They Are Used

We strictly practice data minimization. The application requests only the core permissions required for exam integrity:

  • Camera (android.permission.CAMERA):
    Used solely to scan QR codes for quick navigation to the school's examination server URL. The camera frames are processed locally in temporary device memory (RAM) and are never captured, recorded, stored, or transmitted to any remote servers.
  • Internet & Network State (INTERNET & ACCESS_NETWORK_STATE):
    Required to connect your device to the institution's examination web portal (such as Moodle, Google Classroom, school LAN server, or customized CBT portals).
  • Screen Awake / Lock Prevention (WAKE_LOCK):
    Prevents the device from sleeping or timing out while a candidate is reading and answering exam questions.
  • Lock Task Mode & Device Administration (Optional):
    Enables Android's built-in Kiosk Lock Task functionality to disable the Home, Recents, and Status Bar gestures during the test, ensuring exam fairness without intruding on personal files.

4. Children's Privacy (COPPA Compliance)

Because this application is deployed in elementary, middle, and high schools, we are committed to complying with the Children's Online Privacy Protection Act (COPPA) and international student data privacy guidelines.

The Application does not collect personally identifiable information from children under 13, does not feature social interaction, and does not serve advertisements.

5. Data Retention & Deletion Rights

Because we do not operate a remote user database, we do not hold personal records on our servers.

Users can instantly delete all locally stored preferences (such as previous server URLs) by going to: Android Settings > Apps > Vault CBT Kiosk > Storage > Clear Data, or by simply uninstalling the application.
